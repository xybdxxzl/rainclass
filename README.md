# 雨课堂助手

## 使用场景

雨课堂助手面向使用雨课堂开展教学的日常课堂，提供电脑端和安卓端，方便在上课时查看题目、核对答案，并在课后回顾课堂内容。

- **课堂提醒与作答**：监听正在进行的课程，收到题目后立即展示题干、选项和剩余时间，直接选择或填写答案。
- **模型辅助理解**：使用大模型生成参考答案；电脑端还支持查看解析和继续追问。模型处理期间也可以先手动作答。
- **查看处理状态**：显示当前用户名、课程连接和题目接收情况，区分尚未收到题目、题面获取失败、模型处理中、模型超时等状态。
- **课后复习**：查看历史题目、模型建议、人工答案和提交结果，按课程、日期、状态或关键词查找记录。
- **期末资料归档（电脑端）**：选择课程和学期日期范围，批量收集可访问的历史课堂课件、习题与已公布答案，分别导出课件和习题，支持每题后紧跟答案或末尾答案附录。

## 技术栈

| 模块 | 技术 | 用途 |
| --- | --- | --- |
| 电脑端界面 | Python、PyQt5 | 课堂工作台、设置、答题与历史记录界面 |
| 电脑端网络通信 | Requests、websocket-client | 登录验证、课程查询、课堂事件接收和答案提交 |
| 安卓端 | Java、Android SDK、OkHttp | 原生界面、前台监听服务、HTTP 与 WebSocket 通信 |
| 大模型接入 | OpenAI 兼容的 Chat Completions 接口 | 接入 DeepSeek、千问、Gemini 或自定义模型服务 |
| 本地存储 | SQLite | 按账号保存题目历史和处理结果 |
| 语音提醒 | pyttsx3、Android TextToSpeech | 题目、点名及课堂事件的语音提示 |
| 安卓构建 | Gradle、Android Gradle Plugin | 编译与生成 APK 安装包 |

## 使用方式

### 电脑端（Windows）

1. 安装 **Python 3.10–3.12**。
2. 下载并解压本仓库源码，或使用 Git 克隆：

   ```powershell
   git clone https://github.com/xybdxxzl/rainclass.git
   cd rainclass
   ```

3. 双击项目根目录中的 **`启动雨课堂.cmd`**。首次启动需要联网，脚本会创建运行环境并安装依赖。
4. 打开程序后，按提示使用微信扫码登录雨课堂。

也可以在项目根目录的 PowerShell 中启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1
```

### 安卓端

1. 前往本仓库的 **[Releases](https://github.com/xybdxxzl/rainclass/releases)**，下载对应版本附带的 **APK 安装包**。
2. 在 **Android 8.0 及以上**的手机上安装，按系统提示允许该来源安装应用。
3. 打开应用，通过雨课堂官方登录页面完成短信或密码登录；如果没有自动返回应用，可点击“我已登录”。
4. 按提示开启通知权限。需要在后台持续接收课堂提醒时，请在手机系统设置中允许应用后台运行。

### 配置大模型

两端都可以在设置中配置模型：

1. 选择 DeepSeek、千问、Gemini 或自定义接口。
2. 填写服务商提供的 **API Key**、接口地址和模型名称。
3. 点击 **“测试大模型连接”**，查看测试结果和耗时，再保存配置。

图片题需要使用支持图片输入的模型。模型调用使用你填写的服务商账号，可能产生相应费用。只需要题目提醒和手动作答时，可以关闭模型答题功能。

### 开始监听与答题

1. 点击 **“开始监听”**，查看当前用户名、课程和连接状态。
2. 收到题目后，直接选择或填写答案；模型开启时，会在后台生成建议，并显示处理进度。
3. 核对答案后点击提交，或按需开启自动提交。**手动修改答案或采用模型建议，会暂停本题自动提交**，之后需手动确认提交。
4. 模型失败或超时时，题面完整且仍在有效作答时间内的题目仍可手动作答。题面缺失时可以重新获取；提交结果未知时，请到雨课堂核对。
5. 上课结束后点击停止监听。需要复习时，打开 **“历史题目”** 查看记录。

电脑端的配置和历史保存在项目 `data` 目录；安卓端保存在应用私有存储。历史按账号区分，重启后保留，电脑与手机各自保存，不自动同步。

## 电脑端：期末复习

1. 登录雨课堂后，点击主窗口顶部 **“期末复习”**。
2. 选择春季或秋季，按学校校历调整开始、结束日期。点击 **“加载我的课程”** 并勾选课程；已归档课程可用 **“从课程地址添加”** 填入官网课程学习日志地址。
3. 点击 **“一键收集所选课程”**。程序扫描日期范围内的历史课堂，保存当前账号可查看的课件页面、习题、已公布的客观题/填空题答案及个人作答。表格显示课件页数、习题数、缺官方答案数和采集状态，日志列出失败项。
4. 可随时取消；已采集内容保留。再次收集会按班级、课次、题目编号去重并重新获取资源，失败的刷新不会清空之前保存的资料。
5. 需要补充答案时，在主窗口设置中配置并启用模型，重新打开复习窗口，点击 **“AI 补充缺失答案”**。只处理缺官方答案且尚未生成参考答案的题目，可能产生模型调用费用；参考答案明确标为 AI，不覆盖官方答案或个人作答。
6. 选择导出内容：默认 **“仅习题（课件另行导出）”**，所有习题按课程与课次汇集，每道题后紧跟答案与解析。需要课件时，改选 **“仅课件”** 再单独导出；也可选择 **“课件＋习题”**。答案位置可改成末尾集中附录，取消 **“包含答案和解析”** 则输出练习版；个人作答默认不导出。点击 **“导出 PDF 复习册”** 或 **“导出离线网页”** 保存。移动离线网页时，请一并移动同名 `_assets` 目录。

归档位于项目 `data/review/` 下，按登录账号隔离，包含 SQLite 数据库和本地图片；重启后可直接按日期查看和导出，不自动跨设备同步。复习采集只读取历史，不提交课堂答案，也不修改官网记录。PDF 使用独立进程中的 PyQt5 原生 PDF 输出，不需要额外安装 PDF 库。

课件仅保存当前账号可见的页面图片，不保证取得原始完整 PPT；教师未公开或接口未提供的答案会明确显示缺失。学期按日期筛选，不代表平台官方学期标签；课程列表默认取学习中的课程，归档课程需通过学习日志地址添加。旧版课堂报告和出现未知分页的日志会提示不支持，不会把不完整结果显示为全部成功。详见[使用与接口说明](docs/final-review.md)及[真实课程验证记录](docs/final-review-validation.md)。

已在“软件设计与体系结构”课程验证本学期 11 个课次，保存 697 个课件展示页和 51 道题：40 道客观题取得官方答案，10 道主观题未提供官方答案，1 道投票题不适用标准答案。该账号仍有两项个人作答附件的图片地址为空，已明确标记，不影响课件和题面保存。实际复习册与离线网页位于本机 `output/final_review/`；`data/`、`output/`、`tmp/` 均不纳入 Git。

按“课件与习题分开、答案紧跟每题”的新排版重新导出的文件位于本机 `output/pdf/split_review/`：习题册 52 页，含全部 51 道题；课件册 699 页，含目录及 697 个展示页，两者均有对应离线网页。仅习题模式跳过没有习题的课次章节，不影响本地归档；仅课件模式仍保留教师原页面自带的题面。

## 开发验证

完成首次启动安装依赖后，可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1 -Check
```

测试覆盖课堂作答、模型超时与草稿保护、本地历史，以及期末复习的日期筛选、账号隔离、采集去重、取消、答案来源、离线网页和 PDF 导出。模拟接口测试不等于所有课程均已通过真实账号验证。

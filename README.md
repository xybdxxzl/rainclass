# 雨课堂助手

电脑端使用 Python / PyQt5，手机端是 `安卓` 目录下的原生 Android 应用。两端均可监听课堂、显示新题、手动作答、生成模型建议和查看本机历史。

## 启动

Windows 双击项目中的 `启动雨课堂.cmd`，也可运行 `Start.ps1`。电脑端需要 Python 3.10–3.12，启动脚本会准备依赖。安卓的安装、权限与源码构建见 [安卓说明](安卓/README.md)。

## 账号与监听

主页显示当前用户名及验证状态。账号验证、课程检测、课堂连接与题目接收分别提示；可查看最近课程检测、课堂消息和题目接收时间。

切换账号会结束旧账号的监听与待答任务。历史记录按账号隔离。尚未收到题目仅表示本机没有接收到题目事件，不能据此判断老师是否已发题。

## 收题与作答

- 收到题目时立即建立记录、显示题面与剩余时间。无需等模型返回，就可单选、多选、填写答案或提交。
- 模型关闭、超时或失败时，完整题目仍可手动作答。题面不完整时显示具体提示，并提供重新获取入口。
- 模型状态独立显示：等待、处理中、重试、成功、超时或失败。题目列表保留多道题目，新增题目不覆盖正在编辑的题目。
- 手动修改或采用建议会暂停本题自动提交。模型迟到时保留为建议，不覆盖人工答案；已提交、取消、过期或停止监听的题目不能再次提交。
- 自动提交只会使用有效答案，模型成功后才开始核对缓冲；限时题预留提交时间。结果未知时不自动重交，请在雨课堂核对。
- 电脑端可主动打开答案核对窗口，也可在主工作区直接编辑。详细解析和追问会额外调用模型。

模型置信度是模型自评，不能代替实际正确率。图片题需要支持图片输入的模型；原图仍可在雨课堂核对。

## 模型配置与连接测试

支持 DeepSeek、千问、Gemini 和自定义 OpenAI 兼容接口，各服务商分别保留配置。

“测试连接”使用当前设置页填写的地址、密钥、模型和超时进行最小真实请求；无需先保存。测试显示耗时与结果，并区分配置、鉴权、限流、网络、超时和返回格式问题。修改配置后旧测试结果失效，异步返回也不会覆盖新配置的状态。测试不会创建课堂题目或提交答案。

课堂模型调用的图片获取、请求及重试共享总等待预算。到时即显示超时，之后返回的结果不会用于作答。

## 历史题目

题目从收到事件时就保存，因此模型失败、超时、取消、未作答的记录也可查看。可按课程、日期、状态和关键词筛选，详情包含题干、选项、模型建议、人工答案、错误原因及提交结果，重启后仍保留。

历史仅保存在当前设备，电脑与手机不自动同步。历史详情为只读；未收到过的题目无法凭空补入历史。

电脑端配置及历史位于项目 `data` 目录；安卓位于应用私有存储。历史库不保存 API Key 或登录凭据。

## 本地检查

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用模拟的课堂和模型响应，覆盖立即手动作答、模型超时和迟到、人工编辑保护、提交互斥、账号隔离、历史持久化和界面行为。真实课堂推送、服务商可用性与手机后台行为需要在登录后验证。

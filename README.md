# RainClassroomAssistant

基于 Python 的雨课堂线上课划水小助手（电脑端课堂工作台）。

## 📖 项目介绍

疫情期间，网课成为了重要的教学方式，为诸位提供了极大的便利。但是，不免有些线上水课，老师不仅讲的内容枯燥无聊、照着 PPT 读，还要整出一系列的活来提升听课率，例如：课堂中途偷袭式发题、点名，将弹幕回答问题记录作为考察平时成绩的依据等。为了解决线上水课不能安心划水的问题，雨课堂小助手应运而生。

---

## ✨ 功能特性

### 已实现功能
- **自动签到**：自动监听并完成课堂签到。
- **大模型自动答题**：支持课堂单选题、多选题、填空题、简答题。
- **图片题识别**：支持识别题干和选项中的图片（需配置支持图片输入的视觉模型）。
- **自动发弹幕**：一定时间内收到一定数量的弹幕后，自动跟风发送相同内容的弹幕。
- **语音提醒**：点名、收到题目等关键情况下的语音提醒。
- **多线程支持**：支持在有多个正在上课课程的情况下同时监听使用。
- **电脑端课堂工作台**：简洁美观的 UI，支持核对弹窗、倒计时缓冲、展开解析与追问。

## 🖥️ 电脑端课堂工作台说明

### 1. 主界面与作答控制
- **状态与题目展示**：主界面显示账号验证状态、正在监听的课程与教师、自动提交开关和当前模型。题目到达后显示题干和剩余时间；生成答案后显示推荐选项、模型自评置信度及不超过 100 字的简短解析。
  > ⚠️ **注意**：置信度不等于实际正确率，需自行核对。现有答案弹窗继续支持修改、提交和取消。
- **自动提交开关**：顶部“自动提交”可以随时关闭。关闭后仍生成答案，但等待手动提交；关闭时会暂停已有待答题目的自动提交，重新开启只影响新题。
- **仅勾选与重算**：“仅勾选”在助手内暂停本题自动提交，不会操作雨课堂页面。重算使用顶部当前模型，期间原倒计时继续；如果用户已编辑或题目已结束，不会覆盖原答案。
- **展开解析与追问**：按需发起额外模型请求并流式显示可见解题说明，不会更改已有答案。
- **统计与缩略图**：Token 及费用取决于接口返回的用量和用户填写的单价，信息不足时显示 `--`，估算不等于服务商账单；多课程统计是本次运行的合计。课件缩略图接口尚未验证，暂时显示提示，图片题请同时在雨课堂查看原图。

### 2. 新版答题核对弹窗流程
- **核对与自动提交倒计时**：答案生成后会弹出核对窗口（选择题可改选，填空与简答可直接编辑）。点击“立即提交”提交当前答案；不操作则默认 **15 秒**后自动提交（可在 `配置 → 答题配置` 调整）。倒计时从答案生成后开始，替代原有随机延迟；接近题目截止时自动缩短，并预留 5 秒提交时间。时间不足时提示人工处理，不提交过期答案。
- **取消与异常处理**：关闭弹窗、按 `Esc` 或点击“取消本题”均取消本题提交；停止监听或退出程序也会取消等待中的答案。多个课程的弹窗相互独立。编辑为空时“立即提交”按钮禁用，倒计时到期会使用最近一次有效答案。提交结果在主界面日志中显示；网络异常导致结果未知时不重复提交，请在雨课堂核对。

## ⚙️ 大模型与题型配置

### 1. 预设与接口设置
- **内置服务商预设**：在 `配置 → 大模型配置` 中内置 **DeepSeek**、**千问（北京／国际）**、**Gemini** 和 **自定义** 预设，选择后自动填写接口地址和模型，各预设分别记住自己的 API Key；地址和模型均可编辑。
  - API Key 需要自行填写，模型须在账号中可用。
  - 千问密钥须与接口地域一致；千问也支持替换为控制台提供的工作空间专属域名。
  - 接口来源：DeepSeek 官方文档、千问官方兼容接口文档、Gemini 官方兼容接口文档。

# 电脑端期末复习

## 数据范围

入口位于主窗口顶部“期末复习”。该窗口使用当前软件账号的登录状态，与内置浏览器登录分别保存。加载课程后可一次勾选多门课，选择日期范围，批量读取期间的历史课堂。春秋学期预设只是日期便捷选项，需按学校校历调整。

目前读取学习中课程列表。需要收集归档课程时，可以添加账号有权访问的学习日志地址，格式为：

```text
https://www.yuketang.cn/m/v2/course/normalcourse/logs/课程ID/班级ID
```

不是浏览器外层的 `https://www.yuketang.cn/web?index` 地址。课程是否能读取，最终取决于该账号当前的访问权限。

## 归档和重试

- 归档包含课程、课次、日期、课件名称、可见页原页码、习题原题面、官方答案、教师解析、个人作答及可选 AI 参考答案。
- 课件接口可能返回更多页面；程序只下载学生可见页。未可见、未发送或教师关闭的页面不应算作已获得。
- 课件和题面图片存为本地文件，不依赖带有效期的签名链接；资源请求不附带登录 Cookie。本地归档不存登录凭据、API Key 或签名图片地址。
- 相同班级、课次只保留一条归档，相同课次的题目按题目编号去重。重复收集会重新请求数据和失败资源，保留上一次可用内容及本次失败标记；不是断点续传文件，也不跳过所有已成功的网络请求。
- “采集完整”表示请求的内容在当前接口范围内取得，不表示每题都有官方答案。“缺官方答案”单独计数。接口结构不符、权限不足、图片下载失败等不会冒充空课堂或成功结果。
- 点击取消后等待当前请求结束，已取得的课次和当前课次部分资料会保留。取消完成后可再次收集。网络请求有超时；不要通过强行结束程序来代替取消。

数据目录为 `data/review/<账号摘要>/review.sqlite3` 与同目录 `assets/`。账号摘要用于分目录隔离，不是对归档内容的加密。若要备份，保存该账号整个目录。

## 答案来源

官方答案只取学生题目详情明确用于展示正确答案的 `content.answer`，支持单选、多选、填空；不根据得分、提交成功、个人答案或模型置信度推断正确答案。主观题在当前接口中有教师解析时保存解析，但不会将解析或个人作答自动改名为标准答案。投票题不适用标准答案，单独标记，不计入缺官方答案数。

“AI 补充缺失答案”需用户主动启动，使用主窗口已配置的模型服务。仅为没有官方答案、也没有已保存 AI 参考答案且题面有效的题目生成建议。图片题需配置支持图片输入的模型。仅有题面图片而没有结构化选项的选择题，会生成可读的参考答案，不虚构选项用于校验，也不进入自动提交路径。失败题可再次启动补充；成功题不重复请求。

## 导出

支持 PDF 与离线 HTML。导出内容可选“仅习题（课件另行导出）”“仅课件”或“课件＋习题”。默认仅汇集习题，按课程/课次整理并连续编号，每道题后紧跟答案与解析；选择“仅课件”会排除习题及答案章节，可单独保存课件文件。课件原页面中自带的题面仍会保留，不会修改或裁剪教师页面。

仅习题模式不输出没有习题的课次章节；这些课次仍保留在本地归档与采集统计中。逐题答案模式适当缩小题面图片的展示尺寸，并减少图片段落的额外行距；较长的题面、解析或个人附件仍可能自然跨页。

答案位置可切换为“答案集中在末尾”，附录编号与题目编号对应。两种排版均保留官方答案、教师解析、AI 参考答案的来源和缺失提示。个人作答默认不导出，可勾选包含个人作答后保留其文字与图片。

取消“包含答案和解析”可输出练习版。“仅课件”模式下答案相关选项禁用。离线 HTML 需与同名 `_assets` 文件夹一起移动。PDF 内嵌图片，可单独复制。缺失或损坏的图片会在导出中保留提示，不会悄悄引用在线地址。

PDF 和 HTML 导出在后台运行。PDF 使用独立的 Qt 渲染进程，隔离字体缓存和 Windows 打印组件的线程问题；取消时停止该渲染进程，未完成文件不替换已有目标 PDF。没有额外的第三方 PDF 依赖。

## 接口依据与实现

接口与参数核对自雨课堂官网公开前端 `web/1.2.354`，随后使用用户在电脑端登录的账号进行真实课程联调；不是通过猜测 URL 生成接口。只读采集使用：

| 功能 | GET 接口 | 主要参数 |
| --- | --- | --- |
| 登录账号核验 | `/api/v3/user/basic-info` | 当前登录 Cookie |
| 学习中课程 | `/v/course_meta/learning_list/` | 无 |
| 课程历史 | `/v/course_meta/classroom_logs` | `course_id`、`classroom_id`、`activity_type=-1` |
| 学生课次信息 | `/api/v3/classroom-report/student/lesson-info` | `lesson_id` |
| 学生课次详情 | `/api/v3/classroom-report/student/detail` | `lesson_id` |
| 学生可见课件 | `/api/v3/classroom-report/student/ppt` | `lesson_id`、`presentationId` |
| 当前学生题目详情 | `/api/v3/classroom-report/problem/student-answer` | `lesson_id`、本账号的 `identityId`、`problemId` |

历史课堂类型取官网定义的 `3` 和 `14`；习题列表字段为 `problem.studentList`，题型字段为 `problem_type`，原页码为 `idx`。程序从当前账号课次信息读取 `identityId`，不遍历其他学生身份。当前官网一次返回历史日志；若未来响应出现未支持的分页标记，程序会明确报错而不是只保存第一页。

- `Scripts/Review.py`：只读客户端、图片保存、SQLite 归档、批量采集及可选 AI 补充。
- `Scripts/ReviewExport.py`：纯本地资源的 HTML 与 Qt PDF 导出。
- `UI/ReviewDialog.py`：日期/课程筛选、后台任务、缺失项和导出界面。
- `tests/test_review.py`、`tests/test_review_export_ui.py`：字段契约、失败恢复、账号隔离、取消和导出测试。

接口可能由平台调整；旧版课堂报告尚不支持。原始 PPT 下载、正式学期元数据、归档课程自动枚举以及其他账号和其他学校的全面兼容性不在已验证范围内。

# 雨课堂助手 · 安卓版

安卓原生版本，最低支持 Android 8.0（API 26）。Android 13 及以上需要授予通知权限，才能可靠看到题目和点名通知。

## 安装与使用

1. 在手机上安装项目中的 APK。首次通过浏览器或文件管理器安装时，系统可能要求允许该应用安装未知来源的应用。
2. 打开“雨课堂助手”，默认进入官方登录页并尝试切换到短信登录；也可在官方页面切换手机号密码或邮箱密码。按页面要求接受协议并完成人机验证。登录成功后应用会尝试自动识别；如未自动跳转可点“我已登录”。需先在雨课堂现有账号中绑定手机号。“其他方式”保留扫码和手动填写 sessionid。如果官方页面调整了布局，可手动选择“账号登录”及“短信登录”。
3. 在设置中选择 DeepSeek、千问、Gemini 或自定义接口，输入对应服务商的 API Key 和模型名称并保存。图片题需要服务商和模型支持图片输入。
4. 点击“开始监听”。前台服务会显示持续通知并自动检测在课课程。生成答案后，应用在前台时打开核对界面；在后台时发送题目通知，点击即可查看。默认 15 秒后提交最近一次有效答案，可修改倒计时、立即提交或取消本题。
5. 不再使用时点击“停止”，会停止监听并取消尚未提交的待答题目。老师点名会收到通知；自动弹幕和语音提醒可在设置中启用。

应用配置、登录状态和 API Key 保存在本机应用私有存储中（当前未额外加密），卸载应用会删除；不会自动复制电脑里的密钥或登录信息。请只在自己信任的设备上填写凭据。

Android 的省电策略、厂商后台管理和网络中断可能停止或延迟后台连接；如需持续监听，请按手机系统提示允许通知及后台运行。提交结果不确定时程序不会重复提交，请在雨课堂核对。简答题的提交格式尚需真实课堂验证。

本 APK 为本地构建的调试签名版，供安装体验；它并非应用商店正式发布版本。若之后用不同签名重新打包，Android 可能要求先卸载旧版，卸载会删除本机配置。

## 从源码构建

安装 JDK 17 或 21、Android SDK Platform 35 和 Build Tools 35，设置 `JAVA_HOME` 和 `ANDROID_HOME`。Windows 上双击 **一键打包安卓.cmd** 即可构建；脚本会在临时英文路径构建，再将 APK 放回项目，以兼容当前包含中文的项目路径。也可执行：

```powershell
.\BuildAndroid.ps1
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。如需 Android Studio 开发或运行 `testDebugUnitTest`，请将工程复制到不含中文的路径后打开。正式发布前需要配置你自己的签名，并在真实手机与课堂中验证登录、网络重连、不同题型和后台行为。


## 收题、状态诊断与历史题目

- 首页显示当前账号姓名与验证状态，监听状态来自课程 WebSocket 握手与初始化结果。多课程部分断线时明确显示“部分课程断线重连”，同时显示最近课程检测、课堂消息、收到题目的时间及题数。
- 收到题目后立即建立记录、发送通知并开放手动选择和输入，不再等待模型成功。关闭模型、模型超时、鉴权失败、无效返回时仍能手动提交完整答案；题面或选项缺失会显示获取状态，并可重新获取。
- 模型处理、重试、成功、超时和失败独立显示。总等待上限包括图片获取、请求和重试；限时题预留 5 秒提交时间。人工修改会暂停本题自动提交，迟到模型只更新建议，点击“采用模型建议”可明确采纳。空值和部分填写的草稿会保留，禁止提交不完整答案。
- 时限信息缺失与已过期分开显示。时限待确认时可先编辑草稿，补全真实时限后才能提交；不会把未知时限当作不限时题自动提交。
- 模型设置页的“测试大模型连接”使用当前未保存的地址、密钥和模型，发送最小测试题并验证返回。显示耗时及测试时间；配置变更会让先前结果失效。测试和真实题目共用客户端逻辑，测试不写题目历史、不提交课堂答案，最多等待 30 秒，可能产生少量模型调用费用。
- 历史从收到题目时保存到应用私有 SQLite 数据库，包括模型失败、取消和过期题。按当前账号查询，可筛选课程、日期、作答状态和模型状态，搜索题干或答案；详情只读，可查看建议、人工答案、耗时及提交结果，重启后仍保留。历史不保存 API Key 或 sessionid；不提供跨设备同步。
- 切换登录账号会停止旧账号监听，成功验证后保存新账号资料。提交结果未知时不会自动重复提交。

单元测试覆盖收到即手动提交、模型失败仍可作答、人工草稿保护、迟到模型、未知时限补全、一次完成、多账号课次隔离、历史失败快照及模型响应验证。真实课堂和手机后台表现仍需设备实测。
